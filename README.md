# Reto 1: De la Semilla a la Raíz

## Descripción

Evolución del Reto 0 a una aplicación Spring Boot con persistencia real. Incluye entidades JPA (`Cliente`, `Producto`, `Empleado`), repositorios con `JpaRepository`, base de datos H2 en memoria, consola H2 y datos iniciales cargados desde `import.sql`.

## Requisitos

- Java 25
- Maven (o el wrapper incluido `mvnw`)
